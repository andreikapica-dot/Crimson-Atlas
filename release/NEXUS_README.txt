CRIMSON ATLAS 0.2.0-beta.4

NEXUS INSTALLATION

1. Extract the complete archive to a normal writable folder.
2. Run "Crimson Atlas.exe" from that folder.
3. Start Crimson Desert normally. Administrator rights are not required.
4. Crimson Route 6.9.4+ with Local API enabled is optional and only required for route building.

Keep every extracted file together. This Nexus package contains the unpacked,
compiled application rather than the NSIS/7z self-extracting executable that
can be misidentified by automated file scanners. It contains no project source
tree, development environment, tests, or map-building tools.

Hotkeys:
Ctrl+Shift+A - hide/show the main Atlas window
Ctrl+Shift+N - hide/show the compact navigation window
