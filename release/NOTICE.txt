CRIMSON ATLAS - BETA NOTICE

Crimson Atlas is an unofficial fan-made companion tool and is not affiliated
with, endorsed by, or sponsored by Pearl Abyss. Crimson Desert and related
names, artwork, and game assets belong to their respective owners.

This public repository contains source code only. Map images, marker datasets,
icons, extracted game assets, diagnostics, and packaged builds are deliberately
excluded. Their absence from this repository is intentional.

The application interacts with a running game process to read coordinates and
perform user-requested teleport operations. Use it at your own risk and review
the current game rules before use.
