# Crimson Atlas 0.2.0-beta.1

## Что нового

- добавлено отдельное компактное окно навигации с маршрутом, игроком и видимым конечным значком выбранной цели;
- исправлено мгновенное повторное появление основного окна после `Ctrl+Shift+A`;
- раскрытые списки языков больше не закрываются из-за фонового поднятия окна поверх остальных;
- добавлены корейский, упрощённый китайский, традиционный китайский и португальский языки для интерфейса и всех 505 типов меток;
- категория торговых постов обновлена по актуальной публичной карте MapGenie: 44 точки вместо 36;
- непереведённый тип `Inn` переименован в «Таверна» / `Tavern`;
- острова Бездны возвращены в исправленном масштабе;
- для Nexus Mods добавлен отдельный архив без вложенного NSIS/7z-запускателя.

## Управление

- `Ctrl+Shift+A` — скрыть или показать основное окно;
- `Ctrl+Shift+N` — скрыть или показать окно навигации.

Для маршрутов требуется Crimson Route 6.9.4 или новее с включённым Local API.
